# Music School Management System - PST3

## Overview

This project is the PST3 version of the Music School Management System (MSMS).

The program has been redesigned using Object-Oriented Programming (OOP).
The system separates the program into Model, Controller, and View components.

The program can manage students, teachers, courses, attendance, and daily lesson schedules.
